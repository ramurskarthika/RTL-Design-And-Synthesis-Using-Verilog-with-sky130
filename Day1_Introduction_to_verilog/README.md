DAY 1 : INTRODUCTION TO VERILOG RTL DESIGN AND SYNTHESIS

-Set up the tool environment on Virtual Box.

-Implemented a **GOOD MUX** Design using iverilog.

-Simulated the design using Icarus Verilog and viewed the waveform output in GTKWave.

-Synthesized the design using Yosys.
